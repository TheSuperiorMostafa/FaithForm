# Church website repair log

Scope: existing website creation, editing, preview, publishing, public pages, domains and inbox; the reported blockers connecting recordings to sermons and People to app accounts. Unrelated working-tree changes are preserved. Release snapshot preserves main’s existing publication, CSS authorization, preview, URL normalization and upload probe safeguards. Migrations were committed on main and applied to the explicitly selected FaithForm production project; the application release follows them.

## Content and publication model

The renderer merges section defaults → theme defaults → public church profile → generated section props → church/page/section manual overrides. Arrays replace whole arrays; null clears a value. Church facts stay in the shared profile. Manual copy stays in `site_overrides`; no competing published-content store was added.

Publishing controls public availability. Once online, successful autosaves affect the live site immediately. Taking it offline preserves content and blocks anonymous pages/contact submissions. Preview requires authorized dashboard access to the same church. Generated narrative and manually authored lists remain authored content: changing a profile fact does not rewrite a pastor's paragraphs. New fallback-generated program lists now inherit current service facts instead of freezing them.
