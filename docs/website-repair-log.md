## Content and publication model

The renderer merges section defaults → theme defaults → public church profile → generated section props → church/page/section manual overrides. Arrays replace whole arrays; null clears a value. Church facts stay in the shared profile. Manual copy stays in `site_overrides`; no competing published-content store was added.

Publishing controls public availability. Once online, successful autosaves affect the live site immediately. Taking it offline preserves content and blocks anonymous website pages/contact submissions. Published recording watch links have their own publication state in Live → Recordings; taking the website offline does not unpublish those recordings. Both confirmations now explain that distinction. Preview requires authorized dashboard access to the same church. Generated narrative and manually authored lists remain authored content: changing a profile fact does not rewrite a pastor's paragraphs. New fallback-generated program lists now inherit current service facts instead of freezing them.
